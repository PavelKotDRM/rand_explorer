# rand_explorer

[English version](../README.md)

Интерактивное настольное приложение с ускорением на GPU, написанное на Rust с использованием egui для изучения, визуализации и сравнения возможностей экосистемы crate `rand`.

---

## Возможности

* Генерация примитивов различных скалярных типов (`u8`..`u128`, `f32`, `f64`, `bool`, `char`) в потоковом и пакетном режимах.
* Исследование диапазонов: полуоткрытых и включительных интервалов с проверкой корректности в реальном времени.
* Выборка из статистических распределений с гистограммами и сводной статистикой.
* Операции над коллекциями и последовательностями, включая демонстрации `choose`, `choose_multiple` и `shuffle`.
* Переключение алгоритмов генерации случайных чисел и микробенчмаркинг детерминированных генераторов.
* Просмотр метаданных сборки: Git, компилятор, целевая платформа и информация о зависимостях.

---

## Архитектура и рендеринг

* GUI-фреймворк: egui / eframe
* Графический бэкенд: OpenGL через glow
* Основной движок: rand 0.10+

## Начало работы

### Предварительные требования

* Инструментарий Rust (редакция 2024 или последняя стабильная версия)
* Компилятор C и CMake, если они требуются нативным зависимостям

### Сборка и запуск

```bash
cargo run --release
```

### Проверка качества кода (Rust)

Перед созданием pull request рекомендуется выполнить базовые проверки:

```bash
# 1) Проверить форматирование, не изменяя файлы
cargo fmt --all -- --check

# 2) Запустить линтеры и считать предупреждения ошибками
cargo clippy --workspace --all-targets --all-features -- -D warnings

# 3) Запустить тесты
cargo test --workspace --all-features

# 4) Собрать документацию и считать предупреждения ошибками
RUSTDOCFLAGS="-D warnings" cargo doc --workspace --all-features --no-deps
```

Быстрое исправление форматирования:

```bash
cargo fmt --all
```

Проверки безопасности и зависимостей (рекомендуется):

```bash
# Установить один раз
cargo install cargo-audit cargo-deny cargo-outdated cargo-udeps

# 1) Проверить рекомендации по безопасности (RustSec)
cargo audit

# 2) Проверить политики: лицензии, рекомендации, запреты и источники
cargo deny check

# 3) Получить отчёт об устаревших зависимостях
cargo outdated --workspace

# 4) Найти неиспользуемые зависимости
cargo +nightly udeps --workspace --all-targets
```

Примечание: в Rust не существует конечного списка «всех возможных инструментов». Перечисленные команды охватывают наиболее распространённые практические проверки: стиль, линтинг, тесты, документацию, безопасность и состояние зависимостей.
