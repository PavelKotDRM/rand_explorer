# Technical Specification (SRS) for `rand_explorer`

## 1. Project Overview

* **Project Name:** `rand_explorer`
* **Programming Language:** Rust (Edition 2024 / current stable compiler release)
* **Application Type:** Cross-platform desktop GUI application (primary support for Windows and Linux).
* **Objective:** Create an interactive sandbox designed to demonstrate, benchmark, and visually explore the full feature set of the Rust `rand` crate ecosystem using the `egui` immediate-mode GUI framework.

---

## 2. Technology Stack & Dependencies

| Component / Library | Purpose / Configuration Requirements |
| --- | --- |
| **`eframe` / `egui**` | Primary GUI framework. On Windows, enforce the `glow` (OpenGL) backend via `eframe::Renderer::Glow`. |
| **`egui_plot`** | Real-time plotting of distribution histograms, theoretical Probability Density Functions (PDF), and statistical charts. |
| **`rand`** (v0.9+) | Core random number generation engine (leveraging current APIs: `rand::rng()`, `random_range()`, `rand::distr::*`). |
| **`rand_distr`** | Extended statistical distributions (Normal, Cauchy, Gamma, Poisson, Binomial, etc.). |
| **`rand_chacha` / `rand_pcg**` | Algorithmic PRNGs with explicit seeding (`SeedableRng`) for deterministic reproducibility. |
| **`vergen-gitcl` / `vergen-cargo**` | Build-time metadata generation (`build.rs`). Collects Git commit hashes, build targets, Rust version, and explicit dependency versions. |
| **`serde` / `serde_json**` | State serialization, preset saving, and sample export. |

## 4. GUI Architecture & `egui` Feature Utilization

The UI must leverage the full spectrum of `egui` widgets and patterns:

* **Layout Structure:**
* `TopBottomPanel`: Global menu bar, light/dark theme switcher, and bottom status bar (rendering backend, current FPS, seed status).
* `SidePanel`: Global RNG controls (seed input, engine selection, re-seed trigger).
* `CentralPanel`: Tab content viewport.


* **Navigation:** Tabbed interface with segmented buttons or persistent tabs.
* **Interactive Widgets:**
* `Slider` and `DragValue` with logarithmic scaling for sample sizes ($N = 10 \dots 1\,000\,000$).
* `Color32` and `RichText` for entropy heatmaps and state indicators.
* Modals (`egui::Window`) for sample inspection and contextual `.on_hover_text()` tooltips across all controls.
* Collapsible sections (`CollapsingHeader`) displaying copyable, syntax-highlighted Rust code snippets corresponding to current UI parameters.
* High-performance list visualization with `egui::ScrollArea` row virtualization for large sample buffers.

## 5. Functional Requirements by Module

### 5.1. Tab: Primitives & Scalars

* Live generation of scalar primitives: `u8`..`u128`, `i8`..`i128`, `f32`, `f64`, `bool`, `char`.
* Stream generation mode with a user-configurable update interval (ms).
* Interactive "Coin Flip" and "Dice Roll" visualizers with cumulative outcome statistics.

### 5.2. Tab: Ranges & Intervals

* Interactive boundary configuration for inclusive (`..=`) and half-open (`..`) ranges.
* Support for arbitrary numeric types (e.g., negative float intervals like `[-10.0..10.0)`).
* Real-time bounds validation preventing zero-width or inverted ranges without runtime panics.

### 5.3. Tab: Distributions & Plotting

* Distribution suite: `Uniform`, `Bernoulli`, `Standard`, `Normal`, `Exponential`, `Poisson`, `WeightedIndex`.
* Dynamic parameter modification ($\mu$, $\sigma$, $\lambda$, custom weight arrays).
* Real-time plotting via `egui_plot`:
* Dynamic histogram binning based on sample size.
* Theoretical PDF curve overlay over sampled bins.
* Summary statistics calculation: Sample Mean ($\bar{x}$), Variance ($s^2$), Standard Deviation ($s$), Min, Max.



### 5.4. Tab: Sequences & Iterators

* Demonstrations of `choose()`, `choose_multiple()`, and `choose_weighted()`.
* Interactive array `shuffle()`: visual item reordering (cards, arrows, lists) with step-by-step state diffs.
* Password and string generator based on custom character pools.

### 5.5. Tab: RNG Engines & Determinism

* Switchable generator backends: `ThreadRng`, `StdRng`, `SmallRng`, `ChaCha8Rng`, `ChaCha20Rng`.
* Seed Management: Hex/decimal manual seed input, random seed generation, and side-by-side stream verification for determinism checks.
* Integrated micro-benchmark: throughput test (MB/s and elapsed milliseconds) for generating $10^7$ numbers.

### 5.6. Tab: System & Build Info (`vergen` Integration)

* Git metadata: commit SHA, commit timestamp, current branch.
* Compiler context: `rustc` version, host/target triple, cargo profile (`debug` / `release`).
* **Dependency Table:** Complete list of transitively bundled crate versions emitted by `vergen-cargo`.
* Active graphics backend confirmation (verifying active `Glow` OpenGL context on Windows).

## 6. Build Configuration & Implementation Details

### Build-Time Metadata (`build.rs`)

```rust
fn main() -> Result<(), Box<dyn std::error::Error>> {
    vergen_gitcl::Emitter::default()
        .add_instructions(&vergen_gitcl::GitclBuilder::all_git()?)?
        .emit()?;
        
    vergen_cargo::Emitter::default()
        .add_instructions(&vergen_cargo::CargoBuilder::all_cargo()?)?
        .emit()?;
        
    Ok(())
}

```

### Windows Glow Renderer Configuration (`src/main.rs`)

```rust
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]

use eframe::egui;

fn main() -> eframe::Result<()> {
    let mut native_options = eframe::NativeOptions::default();
    
    // Explicitly enforce the Glow (OpenGL) renderer
    native_options.renderer = eframe::Renderer::Glow;
    native_options.viewport = egui::ViewportBuilder::default()
        .with_inner_size([1100.0, 750.0])
        .with_min_inner_size([800.0, 600.0])
        .with_title("rand_explorer");

    eframe::run_native(
        "rand_explorer",
        native_options,
        Box::new(|cc| Ok(Box::new(rand_explorer::App::new(cc)))),
    )
}

```

# rand_explorer

An interactive, GPU-accelerated desktop application written in **Rust** using **egui** to explore, visualize, and benchmark the capabilities of the `rand` crate ecosystem.

---

## Features

* **Primitive Generation:** Scalars (`u8`–`u128`, `f32`, `f64`, `bool`, `char`) with stream and batch modes.
* **Range Exploration:** Interactive half-open (`..`) and inclusive (`..=`) range sampling.
* **Statistical Distributions:** Live sampling and histogram visualizer with PDF curve overlays (`egui_plot`) for `Normal`, `Uniform`, `Poisson`, `Bernoulli`, and `WeightedIndex`.
* **Collection Operations:** Interactive visualizers for `.choose()`, `.choose_multiple()`, and slice `.shuffle()`.
* **PRNG Engine Benchmarking:** Determinism testing with custom seed inputs across `ThreadRng`, `StdRng`, `SmallRng`, and `ChaCha`.
* **Comprehensive Build Metadata:** Built-in system inspector displaying Git commit data, compiler targets, active rendering backends, and full crate dependency trees powered by `vergen`.

---

## Architecture & Rendering

* **GUI Framework:** [egui](https://github.com/emilk/egui) / [eframe](https://github.com/emilk/egui/tree/master/crates/eframe)
* **Graphics Backend:** OpenGL via `glow` (enforced on Windows for stability and lightweight footprint).
* **Core Engine:** [rand](https://github.com/rust-random/rand) 0.9+
